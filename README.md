## 🚀 Project Structure

Inside of your Astro project, you'll see the following folders and files:

```text
/
├── public/
│   └── favicon.svg
├── src
│   ├── assets
│   │   └── astro.svg
│   ├── components
│   │   └── Welcome.astro
│   ├── layouts
│   │   └── Layout.astro
│   └── pages
│       └── index.astro
└── package.json
```

To learn more about the folder structure of an Astro project, refer to [our guide on project structure](https://docs.astro.build/en/basics/project-structure/).

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |

# la-romanita
LA ROMANITA 
ANÁLISIS ESTRATÉGICO PARA LA EXPANSIÓN DIGITAL


-----
1. Capacidad Operativa y Límites de Fabricación (El Techo de Producción)

Antes de cerrar acuerdos con hoteles que manejan volúmenes masivos, es esencial determinar el potencial productivo de la fábrica actual.
Capacidad máxima actual: ¿Cuántos kilos de pasta (fresca, rellena, congelada) y cuántas unidades de masa/taloa se pueden producir por día/semana con la maquinaria y el personal actual?
Capacidad ociosa: ¿Cuánto se está fabricando hoy en día y qué porcentaje de la fábrica está "parado" o infrautilizado?
Cuellos de botella: ¿Qué limita la producción? (¿Es el tiempo de congelado rápido, el espacio de almacenamiento en frío, la velocidad de la laminadora o la mano de obra?).
Escalabilidad a corto plazo: Si entra un pedido grande de una cadena hotelera, ¿se puede doblar la producción simplemente añadiendo un turno de noche o hace falta comprar maquinaria pesada?
Tiempos de preparación (Lead Time): Desde que un restaurante hace un pedido online de, por ejemplo, 50 kg de sorrentinos, ¿cuántos días se necesitan para producirlo, congelarlo (si aplica) y tenerlo listo para envío?
2. Radiografía de Costes y Política de Precios (B2C vs. B2B)

La plataforma digital manejará dos tarifas (minorista y mayorista). Para su correcta configuración y para definir el margen de negociación con hoteles, el gerente debe desglosar los siguientes puntos:
Escandallos precisos: Coste exacto de materia prima por kilo de producto (harina, sémola, rellenos de carne, quesos, etc.) y de los envases (cajas para hostelería vs. cajas para particulares).
Costes fijos vs. variables: Análisis del impacto del aumento de volumen en el coste por kilo (economía de escala). A más volumen, la materia prima debería abaratarse.
Precios de Venta Minorista (PVM): Los precios actuales de cara al público general en la web/tienda.
Precios de Venta Mayorista (PVMay):
¿Cuál es el pedido mínimo (MOQ) en kilos o euros para que a un restaurante se le aplique la tarifa de profesional?
¿Existe una escala de descuentos por volumen? (Ej: Precio X por 10 kg, Precio Y por más de 50 kg).
Margen de maniobra: Cuál es el precio mínimo absoluto al que se puede vender a un gran distribuidor o cadena hotelera manteniendo un margen saludable.
3. Logística y Distribución en Mallorca

El transporte en frío es el punto crítico para la pasta fresca y productos artesanales. Si la plataforma permite la compra online, la entrega debe ser impecable.
Cadena de frío: ¿La fábrica cuenta con vehículos refrigerados propios o se va a externalizar la entrega en la isla con empresas de logística capilar en frío (como Seur Frío, Logística de Mallorca, etc.)?
Zonas y días de reparto: ¿Se repartirá en Palma a diario y en el resto de la isla (Pollença, Alcúdia, Cala d'Or) ciertos días a la semana? Esto debe programarse en la plataforma.
Stock de seguridad: ¿Se trabajará bajo pedido (just-in-time) o se mantendrá un stock de producto congelado en cámaras para dar salida inmediata a las compras online?
4. Requisitos de la Plataforma Digital (B2B + B2C)

Para optimizar y maximizar las ventas, la plataforma debe integrar funcionalidades específicas para el sector Horeca (Hoteles, Restaurantes y Catering):
Acceso Profesional (Login Horeca): Cuando un restaurante u hotel se registre con su CIF, debe acceder a precios diferentes (sin IVA, con su tarifa mayorista y con formatos de empaquetado grandes de 2 kg o 5 kg).
Gestión de Alérgenos y Fichas Técnicas: La web debe permitir la descarga en PDF de las fichas técnicas (ingredientes, alérgenos, trazabilidad, valores nutricionales), requeridas por los jefes de cocina.
Pasarela de pago flexible para empresas: Definir si la plataforma permitirá la "compra a crédito" para clientes VIP verificados, ya que los hoteles y restaurantes suelen exigir facturación mensual o pagos a 30/60 días, a diferencia de los particulares que pagan con tarjeta o Bizum al momento.
Sincronización de Stock: El sistema debe avisar a producción automáticamente si el stock online llega a cero para evitar vender productos que no pueden ser fabricados.
5. CHECKLIST DE INFORMACIÓN CRÍTICA PARA VENTAS Y COMERCIANTES (A COMPLETAR POR GERENCIA)

Para que el equipo comercial pueda cerrar acuerdos B2B y configurar la plataforma digital con precisión, el gerente debe proporcionar respuestas claras y definitivas a los siguientes puntos clave, extraídos del análisis estratégico:A. Capacidad y Tiempos de Entrega
Capacidad de Producción Máxima: Kilos de pasta total (fresca/rellena/congelada) que la fábrica puede producir por semana.
Tiempo de Preparación (Lead Time) Estándar: Número de días necesarios desde la recepción de un pedido B2B de volumen hasta que está listo para el envío.
Umbral de Escalabilidad: Confirmar si un pedido masivo requiere añadir un turno de noche o si es necesario adquirir maquinaria nueva.
B. Política Comercial y Precios
Tarifa PVM (Minorista): Listado de Precios de Venta al Público (PVP) para la web/tienda.
Tarifa PVMay (Mayorista Base): Tarifa inicial de precios para profesionales (restaurantes, hoteles).
Pedido Mínimo (MOQ): Cantidad mínima (en kilos o euros) requerida para aplicar la tarifa de profesional.
Escala de Descuentos por Volumen: Detalle de los tramos de descuento aplicables a partir de ciertos umbrales de pedido (ej. +50 kg).
Precio Mínimo de Venta: Definición del precio mínimo absoluto para negociaciones con grandes cadenas, manteniendo un margen saludable.
C. Logística y Documentación
Método de Transporte en Frío: Confirmación de si se utiliza flota propia o logística capilar externalizada (ej. Seur Frío).
Frecuencia de Reparto Detallada: Definición de los días específicos de reparto para cada zona de Mallorca (Palma vs. zonas foráneas como Pollença, Alcúdia, Cala d'Or).
Política de Stock: Decisión sobre si la venta online se gestionará con stock de seguridad (para envíos inmediatos) o bajo pedido (just-in-time).
Fichas Técnicas: Confirmación de la disponibilidad inmediata de las fichas técnicas de productos (alérgenos, ingredientes, valores nutricionales) en formato PDF.
Condiciones de Pago B2B: Decisión final sobre la habilitación de la "compra a crédito" (pago a 30/60 días) para clientes Horeca verificados.
